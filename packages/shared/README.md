# @easytestdata/shared

Realistic test data for QuickBooks Online sandboxes.

Shared pieces of EasyTestData: the request schemas (Zod), constants such as the deployment
limits, and the typed API client used by the web app. It is published because
[`@easytestdata/server`](https://www.npmjs.com/package/@easytestdata/server) depends on it; you
don't need to install it yourself.

[![npm](https://img.shields.io/npm/v/@easytestdata/shared)](https://www.npmjs.com/package/@easytestdata/shared)
[![License: Apache-2.0](https://img.shields.io/badge/License-Apache--2.0-blue.svg)](LICENSE)

To use EasyTestData, start with the [`easytestdata`](https://www.npmjs.com/package/easytestdata)
CLI or the [repository](https://github.com/easytestdata/easytestdata).

Requires Node.js 22.13 or later. Licensed under [Apache-2.0](LICENSE).
