# Changelog

EasyTestData is released with [Changesets](https://github.com/changesets/changesets). Release
notes are on [GitHub Releases](https://github.com/easytestdata/easytestdata/releases), and each
published package gets its own `CHANGELOG.md` with its first release:

- `easytestdata` (CLI): `packages/cli/CHANGELOG.md`
- `@easytestdata/core`: `packages/core/CHANGELOG.md`
- `@easytestdata/qbo-client`: `packages/qbo-client/CHANGELOG.md`
- `@easytestdata/shared`: `packages/shared/CHANGELOG.md`
- `@easytestdata/server` (the API server and the web app it serves for `easytestdata ui`):
  `packages/server/CHANGELOG.md`

See [docs/releasing.md](docs/releasing.md).

The first public release is 0.1.0.
