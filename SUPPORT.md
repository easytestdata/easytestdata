# Getting help

- **Questions, ideas, and show-and-tell:** [GitHub Discussions](https://github.com/easytestdata/easytestdata/discussions)
- **Bugs and feature requests:** [GitHub Issues](https://github.com/easytestdata/easytestdata/issues/new/choose)
- **Security vulnerabilities:** report privately via [GitHub security advisories](https://github.com/easytestdata/easytestdata/security/advisories/new). See [SECURITY.md](SECURITY.md).
- **EasyTestData Cloud account or data questions:** support@easytestdata.com

EasyTestData is maintained by volunteers, so there's no guaranteed response time. Issues with clear reproduction steps (a `--seed` and `--start-date` make generation reproducible) get fixed fastest.
