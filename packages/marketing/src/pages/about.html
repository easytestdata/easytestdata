About EasyTestData

Realistic test data for QuickBooks Online sandboxes.

Why it exists

Every developer building on QuickBooks Online (QBO) hits the same wall: a sandbox with a handful of records, while real companies have years of invoices, partial payments, credits and payroll. EasyTestData closes that gap by generating a year of financially coherent books for a chosen industry and scenario, loading it into a QBO sandbox, and purging it cleanly afterwards.

Open source first

The whole project (generation engine, QBO client, CLI, API server and web app) is open source under the Apache-2.0 license. You can generate data from the CLI or the playground, run the web app on your own computer with no limits, or use EasyTestData Cloud, a free hosted instance.

Contributions are welcome: industry templates and scenarios are the best first contributions, and bug reports and fixes are always useful. Start with the GitHub repository and the contributing guide.
